## Contracts between I1 and the DOM side (decided; both sides implement their half)

1. `html[data-board]`: I1 sets `document.documentElement.dataset.board = "live"` once the first frame has rendered AND live printing is possible (renderer active, `TIER_BUDGETS[tier].prints`, not calm); otherwise `"still"` once a frame is rendered (2D tier, calm still frame). I2 makes `StaticField.module.css` hide the static field for ANY value (`html[data-board] .field`), and keeps U1's Window rule (static automaton hidden only for `"live"`, never in calm).
2. `html[data-js]`: the pre-paint script sets `"pending"`; I1 (Board/programme) sets `"ready"` at `min(T + 1650 ms, 1800 ms)` where T = board ready, or at 1800 ms after hydration if the board never loads (Providers owns the fallback timer). Never remove the attribute. U5's hero sub-copy reveal keys on `html[data-js="ready"]`; U1's/U4's holds key on its presence.
3. `html[data-capture="on"]`: in capture mode I1 sets it when the capture wave reaches 60 % (DOM h1 → opacity 0 over 300 ms) and removes it when the dissolve passes p ≥ 0.95 scrolling down or the user scrolls back above p < 0.5 (h1 back to 1). I2 adds the CSS in `hero.module.css`: `html[data-capture="on"] .h1 { opacity: 0 }` with a 300 ms opacity transition (never display/visibility; the h1 stays in the a11y tree).
4. `useUI.heroMode`: I1 decides `"capture"` (C ≥ 120, measured capital rows of the h1 ≥ 14, fine pointer, motion full, tier high|mid) else `"echo"` and calls `setHeroMode`. HeroShell (U5) already registers `excl-h1` only in echo mode.
5. Regions (already registered by the DOM): sheets `about|experience|projects|stack|education|contact|footer|menu` (kind sheet; `menu` is 0×0 while the dialog is closed), gaps `gap-*` (kind gap, `word`), holes `window:<projectId>` (kind hole; the windows are `position: sticky` → re-measure hole rects with getBoundingClientRect each rendered frame, ≤ 3 elements), `strip-experience` (kind strip; 0×0 below lg), `hero-h1` (h1), `hero-echo` (echo), `excl-eyebrow|excl-hook|excl-cta|excl-h1` (exclusion), `board-tail` (tail). Ignore empty rects.
6. `bus.progress`: `hero` 0–1 (written by HeroShell each frame from scrollY / (0.6 · heroHeight)), `tape` 0–1, `print:<id>` px ≥ 0 since the printout's top crossed 85 % of the viewport.
7. `html[data-menu="open"]` + `useUI.menuOpen`: while open, visible rects = viewport minus the `menu` sheet only (omit page sheets: `main` is hidden); `bus.setMenuLabel(label, index)` arrives with raw labels — fold them with `normalizeText` from bitmap-font (upper-case, strip accents; drop characters outside the set such as "↗").
8. Readout: I1 never calls `say("KB")` (the Readout derives it from `bus.progress.hero`). I1 sets `useUI.setTelemetry({ cols, rows, fps, renderer, tier })` (fps once per second).
9. `--pitch`: I1 writes the measured pitch to `document.documentElement.style.setProperty("--pitch", px)`; the CSS default (I2, globals.css) must use the same formula with the CORRECT clamp order: `calc(100vw / 72)` below 48rem, `calc(100vw / 120)` 48–64rem, `clamp(5px, calc(100vw / 192), 7px)` at ≥ 64rem.
10. Calm: Providers computes `calm = prefers-reduced-motion || calmPref || saveData || ?tier=static`, keeps `html[data-motion]` and the store in sync (listen to the media query), and I1 calls `bus.setCalm` semantics internally (still frame = 3 % field + still echo name; no sim). Controls (U1) already call `applyCalm` + `useUI.setCalm` + `bus.setCalm`.

## Integrator notice (after Phase 2 launch)
`next.config.ts` was fixed: the Tailwind Turbopack loader rule had been applied to `*.module.css` too, which compiled every CSS Module as plain global CSS (unhashed selectors, empty `styles` imports — the h1 and flap cells had no classes). CSS Modules are now excluded from the loader (`condition: { not: { path: /\.module\.css$/ } }`) and the dev server on :3100 was restarted with the fix. Any screenshot taken before that restart showed a broken page; re-take them. CSS Modules therefore must not use Tailwind directives (`@apply`, `theme()`), only plain CSS and the `--tokens`.
